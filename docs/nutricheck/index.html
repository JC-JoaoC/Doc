nutricheck API

nutricheck — Análise nutricional.

Armazena vitaminas (D, B12, B1, B6, C, A, ácido fólico), minerais (ferro sérico, ferritina, transferrina, saturação de transferrina, zinco, magnésio, selênio) e calcula razões/índices (saturação calculada, índice ferritina/ferro, razão B12/folato, score antioxidante 0-4). Detecta correlações entre nutrientes.

  • Porta dev: 3004
  • Domínio: https://nutricheck.nutricao360.com/
  • Tabela do app: nutri_analyses
  • Auth: cookie __session_nutri (JWT HS256, 1 ano)

Servers

https://nutricheck.nutricao360.com

Autenticação

AUTH sessionCookie

tipo: apiKey • em: cookie • param: __session_nutri

tRPC - analysis

Recebe exams (mapa nome → valor|null), calcula razões/índices e correlações, persiste em nutri_analyses e devolve id, razões e correlações detectadas.

🔒 Auth: sessionCookie

Request body obrig.

    "<chave>": 0
  }
}
PropriedadeTipoDescrição
