API

suporte API

suporte — Chat IA de suporte ao cliente da Nutricao360.

Sessões persistentes (ChatSession + ChatMessage) com RAG sobre itens da KnowledgeBase do tipo support_reference. Cada mensagem é enviada à LLM via OpenRouter junto do contexto recuperado. Acesso é validado por e-mail contra UnifiedSubscriptionService — não há login NextAuth.

  • Porta dev: 3005 (colide com admin; ajustar em deploys paralelos)
  • Auth pública: verificação de assinatura por e-mail
  • Marcador de sessão: títulos começam com [SUPORTE]

Servers

https://suporte.nutricao360.com

Auth

Verificação de e-mail/assinatura.

GET /api/auth/verify-email Valida assinatura e lista sessões recentes ▾

Valida a assinatura do e-mail. Em caso de sucesso devolve o usuário e até 20 sessões com prefixo [SUPORTE] ordenadas por updatedAt desc.

Parâmetros

NomeEmTipoDescrição
email query string (email) obrig.

Respostas

200

Acesso liberado e sessões do usuário.

application/json → object

{
  "hasAccess": true,
  "user": {
    "id": "string",
    "name": "string",
    "email": "user@example.com"
  },
  "sessions": [
    {
      "id": "string",
      "userId": "string",
      "title": "string",
      "createdAt": "2025-01-01T00:00:00Z",
      "updatedAt": "2025-01-01T00:00:00Z"
    }
  ]
}

Chat

Sessões e mensagens do assistente de suporte.

POST /api/chat Envia mensagem ao assistente de suporte ▾

Cria a sessão se sessionId não for enviado. Recupera contexto via RAG em support_reference e chama a LLM. Persiste mensagem do usuário e resposta do assistente em ChatMessage.

Request body obrig.

application/json → object

{
  "email": "user@example.com",
  "message": "string",
  "sessionId": "string"
}
PropriedadeTipoDescrição
email string (email) obrig.
message string obrig.
sessionId string • nullable opcional

Webhooks

Eventos da plataforma Guru.

GET /api/webhook/guru Healthcheck do webhook Guru ▾

Retorna mapa GURU_PRODUCT_PERIODS e flag ok: true.

Respostas

200

OK.

application/json → object

{
  "ok": true,
  "productPeriods": {
    "<chave>": 0
  }
}
PropriedadeTipoDescrição
ok boolean opcional
ex.: true
productPeriods object opcional
POST /api/webhook/guru Evento de assinatura Guru ▾

Valida api_token, persiste o evento e faz upsert em GuruSubscription. Eventos de produtos desconhecidos são logados e ignorados.

Request body obrig.

application/json → GuruWebhookPayload

  "api_token": "string",
  "id": "string",
  "event": "string",
  "status": "string",
  "contact": {
    "email": "user@example.com",
    "name": "string"
  },
  "product": {
    "id": "string",
    "name": "string"
  }
}
PropriedadeTipoDescrição

id string opcional
event string opcional
