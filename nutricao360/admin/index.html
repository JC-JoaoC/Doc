API

admin API

admin — Painel administrativo central da Nutricao360.

Backoffice completo: gestão de admins, usuários finais, exames, planos alimentares, relatórios, suplementos, IA, base de conhecimento (RAG), integrações Hotmart/Guru/FirePay, webhooks de formulários CDA (Etapa 1 e 2) e crons internos. Quase todas as rotas exigem requireAdmin (cookie/JWT NextAuth + role de admin); algumas usam só getServerSession.

  • Porta dev: 3005
  • Auth principal: requireAdmin (NextAuth + role)
  • API externa: GET /api/external/meal-plans/by-email autenticada por x-api-key

Servers

https://admin.nutricao360.com

Autenticação

AUTH adminSession

tipo: apiKey • em: cookie • param: next-auth.session-token

AUTH externalApiKey

tipo: apiKey • em: header • param: x-api-key
