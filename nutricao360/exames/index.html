API

exames API

exames — App de análise de exames laboratoriais da Nutricao360.

Upload de PDFs (OCR via Mistral) ou texto, análise via IA (OpenRouter) com RAG sobre exam_reference, download, SSO por token e integrações Hotmart/Guru. Persiste Exam com analysisStatus (PENDING → APPROVED).

  • Porta dev: 3002
  • Auth: NextAuth (sessão) + e-mail (upload público) + SSOToken

Servers

https://exames.nutricao360.com

Autenticação

AUTH sessionCookie

tipo: apiKey • em: cookie • param: next-auth.session-token

AUTH hotmartHottok

tipo: apiKey • em: header • param: x-hotmart-hottok

AUTH adminToken

tipo: apiKey • em: header • param: x-admin-token

POST /api/exams/upload Upload de exame (PDF OCR ou texto) ▾

Valida assinatura por e-mail (UnifiedSubscriptionService), aplica rate-limit por usuário, persiste Exam (PENDING) e dispara análise em background. Aceita 2 formatos:

  • JSON: { type: 'text', fileName, extractedText, clientName, clientPhone, clientEmail, stage? }
  • multipart: clientName, clientPhone, clientEmail, stage?, file0[, file1]

Request body obrig.

application/json → object

{
  "type": "text",
  "fileName": "string",
  "extractedText": "string",
  "clientName": "string",
  "clientPhone": "string",
  "clientEmail": "user@example.com",
  "stage": 1
}
PropriedadeTipoDescrição
type enum("text") obrig.
fileName string obrig.
extractedText string obrig.
clientName string obrig.
clientPhone string obrig.
clientEmail string (email) obrig.
stage enum(1, 2) opcional

multipart/form-data → object

{
  "clientName": "string",
  "clientPhone": "string",
  "clientEmail": "user@example.com",
  "stage": 1,
  "file0": "<binary>",
  "file1": "<binary>"
}
PropriedadeTipoDescrição
clientName string obrig.
clientPhone string obrig.
clientEmail string (email) obrig.
stage enum(1, 2) opcional

file1 string (binary) opcional
