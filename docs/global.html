Documentação da API para o monorepo HealthCheck Apps — um conjunto de 9 aplicações web voltadas à saúde que compartilham a mesma autenticação, integração de pagamentos (Guru) e banco de dados MySQL. Cada app expõe:

  • Endpoints REST (este documento OpenAPI): callback OAuth, webhook Guru e um gateway tRPC genérico.
  • Procedures tRPC (documentadas em API.md): a maior parte da lógica da aplicação — perfis, análises, histórico, etc. A autenticação é gerenciada via cookie HTTP-only (__session_<APP_ID>) assinado com JWT. O acesso é condicionado ao usuário possuir uma assinatura Guru ativa correspondente a um dos IDs de produto configurados.

Auth

Fluxo de callback OAuth que troca um código de terceiro por um cookie de sessão.

Callback OAuth

Recebe o code de autorização e o state do provedor de identidade externo, troca-os por um token de acesso, busca as informações do usuário, realiza upsert do usuário no banco de dados, emite um token de sessão JWT e o define como cookie HTTP-only. Por fim, redireciona para /.

Evento de assinatura Guru

Recebe eventos de pagamento e assinatura da plataforma Guru. Registra o payload bruto e, em seguida, realiza upsert do registro de assinatura local com base em product.id e status. Eventos referentes a produtos desconhecidos são aceitos, mas ignorados. Autenticação: o corpo deve incluir um api_token correspondente ao GURU_ACCOUNT_TOKEN configurado; caso contrário, a requisição é rejeitada com 401.

Request Body schema: application/json
required
api_token
required
string

Deve corresponder ao GURU_ACCOUNT_TOKEN do servidor.

tRPC

Gateway para a API tRPC. Os procedures não estão documentados aqui — consulte API.md para o catálogo completo. Formato da URL: /api/trpc/{router}.{procedure}.

Invocar uma `query` tRPC

Gateway genérico para queries tRPC. Os inputs são passados via parâmetro de query input como JSON codificado em URL (formato tRPC v10). A autenticação é fornecida pelo cookie de sessão.

sessionCookie
path Parameters
procedure
required
string

Caminho em notação de ponto do procedure a ser invocado, por exemplo: auth.me, profile.upsert, analysis.list. Consulte API.md para o catálogo por app.

query Parameters
input
string

Input do procedure serializado em JSON e codificado na URL.
