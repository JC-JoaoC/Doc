API

aquaflow API

aquaflow — App de rastreamento de hidratação personalizada.

Calcula meta diária de água a partir de peso, atividade física, clima, gestação/ lactação e gera uma estratégia de slots distribuídos ao longo do dia (acordar, pré-refeição, treino, dormir). O usuário marca cada slot como concluído e o app apresenta resumo diário e histórico.

  • Porta dev: 3001
  • Domínio: https://aqua.nutricao360.com/
  • Tabelas do app: aqua_profiles, aqua_intake_records
  • Auth: cookie __session_aqua (JWT HS256, 1 ano)

A maior parte da API é exposta via tRPC v10 sob /api/trpc/{router}.{procedure}. Queries vão por GET com input URL-encoded; mutations por POST com body JSON.

Servers

https://aqua.nutricao360.com
