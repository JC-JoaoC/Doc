API

nutricao API

nutricao — App de análise nutricional da Nutricao360.

Reconhece refeições a partir de foto (modelos de visão da OpenRouter) ou lista textual de alimentos, calcula calorias e macros via segunda chamada de IA, complementa com RAG (nutrition_reference) e persiste em NutritionLog. Histórico/estatísticas por dia/semana e verificação de assinatura por e-mail.

  • Porta dev: 3003
  • Auth: NextAuth (sessão) ou e-mail (cliente sem login)

Servers

https://nutricao.nutricao360.com

Autenticação

AUTH sessionCookie

tipo: apiKey • em: cookie • param: next-auth.session-token

Nutrition

Análise nutricional e histórico.

POST /api/nutrition/analyze Analisa imagem de refeição (vision + analysis) ▾

Recebe uma imagem (≤10 MB) e faz duas chamadas à IA:

1. vision model — descreve a refeição (alimentos e quantidades). 2. analysis model — calcula calorias, macros e devolve resumo nutricional usando RAG.

Aceita autenticação por NextAuth (cookie) ou e-mail no form (validado contra UnifiedSubscriptionService). Persiste o resultado em NutritionLog.

🔒 Auth: sessionCookie

Request body obrig.

multipart/form-data → object

{
  "file": "<binary>",
  "mealType": "breakfast",
  "email": "user@example.com"
}
PropriedadeTipoDescrição
file string (binary) obrig.

Imagem JPG/PNG (até 10 MB).
mealType enum("breakfast", "lunch", "snack", "dinner", "other") opcional
email string (email) opcional

Necessário se o cliente não estiver autenticado.
