HealthCheck Apps

Documentação Swagger

Monorepo com 10 aplicações web que compartilham autenticação, integração com a plataforma Guru e o mesmo banco MySQL. Cada app expõe endpoints REST para callback OAuth, webhook Guru e um gateway tRPC v10.

Notas

Cada app expõe três famílias de endpoints: /api/oauth/callback (callback OAuth), /api/webhook/guru (webhook de assinatura) e /api/trpc/{router}.{procedure} (gateway tRPC v10). A autenticação é feita por cookie HTTP-only __session_<APP_ID>.
