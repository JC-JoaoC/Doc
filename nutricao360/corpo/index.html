API

corpo API

corpo — App de análise corporal da Nutricao360.

Recebe 3 fotos (frente/lateral/costas) + medidas antropométricas e gera análise de composição via modelo de visão da OpenRouter. Persiste BodyAnalysis por e-mail. Endpoints públicos validam assinatura via UnifiedSubscriptionService; report e delete exigem NextAuth.

  • Porta dev: 3004
  • Auth: NextAuth (sessão) + verificação de e-mail para uso público

Servers

https://corpo.nutricao360.com

Autenticação

AUTH sessionCookie

tipo: apiKey • em: cookie • param: next-auth.session-token

Body

Análise corporal, histórico e relatório.

POST /api/body/analyze Analisa composição corporal a partir de 3 fotos ▾

Acesso público — valida assinatura por e-mail. Envia as 3 imagens ao modelo de visão e devolve estimativas (BMI, %BF, MM, etc.). Persiste BodyAnalysis.

multipart/form-data → object
