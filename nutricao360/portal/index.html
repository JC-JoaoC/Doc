API

portal API

portal — Portal do cliente da Nutricao360.

Entrada por e-mail (sem login). Verifica assinatura ativa em Hotmart/Guru pelo UnifiedSubscriptionService e devolve os documentos aprovados/pendentes do cliente, organizados por etapa (planos alimentares, exames, relatórios e suplementos). Também consulta o status de avaliação CSAT na API externa api.nutricao360.com.

  • Porta dev: 3008
  • Auth pública: verificação de assinatura por e-mail (sem cookies)
  • API externa consumida: https://api.nutricao360.com/csat/...

Servers

https://portal.nutricao360.com

Documents

Documentos aprovados e pendências por etapa.

POST /api/documents Lista documentos aprovados e pendências do cliente ▾

Recebe o e-mail no body, valida a assinatura e retorna até 2 itens APPROVED por categoria (meal plans, exams, reports, supplements), cada um com etapa (1 ou 2). Inclui também flags de pendências por etapa: etapa1Pending, etapa2Pending (planos/relatórios em PENDING ou SCHEDULED).

Request body obrig.

application/json → object

{
  "email": "user@example.com"
}
PropriedadeTipoDescrição
email string (email) obrig.

200

CSAT

Status de avaliação do plano alimentar (API externa).

GET /api/portal/evaluation-status Status de avaliação CSAT do plano alimentar ▾

Consulta a API externa de CSAT (api.nutricao360.com) e retorna evaluated | pending | unknown. Falhas externas retornam sempre 200 com status: unknown para não bloquear o portal.

Parâmetros

NomeEmTipoDescrição
email query string (email) obrig.

Respostas

200
