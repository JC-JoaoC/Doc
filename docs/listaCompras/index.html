API

listaCompras API

listaCompras — Planejamento nutricional e listas de compras.

Recebe um PDF de plano alimentar, extrai sua estrutura via LLM (paciente, refeições, opções, equivalentes, alimentos proibidos/riscados), permite ao usuário escolher os alimentos por categoria, gera uma lista de compras semanal com conversão automática de quantidades (cozido → cru/in natura) e, opcionalmente, orientações personalizadas de meal-prep.

  • Tabelas do app: mealPlans, shoppingLists
  • Auth: cookie __session_lista (JWT HS256, 1 ano)

Toda a API de negócio é exposta via tRPC v10 sob /api/trpc/{router}.{procedure}.

tRPC - shoppingList

Geração e histórico de listas de compras + orientações de meal-prep.

POST /api/trpc/shoppingList.generate shoppingList.generate (mutation, protected) ▾

Gera lista de compras semanal a partir dos alimentos escolhidos por categoria. Aplica fatores de conversão (carnes ×2, carbos ÷2, leguminosas ÷2, tubérculos ×0.85–0.90, vegetais "à vontade"), agrupa itens, filtra suplementos/água, deduplica e arredonda para unidades práticas (kg, g, unidades).
